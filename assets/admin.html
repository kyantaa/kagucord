1. Kết nối tới GitHub

Token chỉ được lưu trong trình duyệt của bạn (localStorage), không gửi đi đâu khác ngoài GitHub. Tạo token tại: github.com/settings/tokens (chọn repo kagucord, quyền Contents: Read and write). Dùng máy công cộng thì nhớ bấm "Quên token" khi xong.
